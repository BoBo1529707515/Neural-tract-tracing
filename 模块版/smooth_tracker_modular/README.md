# Neuron Tracker - Smooth Constraint Optimized
(神经元追踪 - 平滑约束优化版)

## 📖 简介 (Introduction)
本项目是一个基于 Python 的神经元轴突生长追踪工具，专为处理复杂的神经元生长时序图像而设计。

不同于传统的静态分割方法，本工具采用**动态点追踪 (Dynamic Point Tracking)** 策略，结合**平滑几何约束 (Smooth Geometric Constraints)**，有效解决了轴突生长过程中的噪声干扰、方向突变和路径跳跃问题。配合全新设计的 **Artistic Light** 风格界面，提供专业、高效且愉悦的科研标注体验。

## ✨ 核心特性 (Features)

### 🎨 艺术化交互界面
- **Artistic Light Theme**: 采用清新蓝白配色 (`#F5F7FA` 背景 + `#74B9FF` 强调色)，营造沉浸式科研环境。
- **现代化控件**: 扁平化圆角按钮、呼吸感内边距设计，操作手感流畅。
- **深度视图控制**: 支持鼠标中键拖拽平移、滚轮缩放，辅以边缘滑块，实现像素级精细操作。

### 📐 智能平滑追踪算法
- **转角限制 (Angle Constraint)**: 严惩非生物学的大角度折返，确保路径平滑。
- **步距限制 (Step Constraint)**: 限制单帧最大生长距离，防止“隐形传输”错误。
- **方向一致性 (Directional Coherence)**: 算法优先沿之前的生长惯性方向搜索，抗噪声干扰能力强。

### 📍 人机协同标注
- **必经点引导 (Waypoints)**: 用户可手动标记关键点，引导算法穿越模糊或交叉区域。
- **实时预览**: 计算结果即时叠加显示，支持确认/取消操作。

### 💾 多维结果导出
- **视频导出**: 生成包含追踪轨迹的 `.mp4` 演示视频。
- **数据导出**: 输出详细的 `.csv` 坐标文件，便于后续定量分析。
- **截图保存**: 一键保存当前帧的高清分析图。

## 🚀 使用方法 (Usage)

1.  **启动程序**:
    ```bash
    python main.py
    ```
2.  **加载数据**:
    - 在界面 `📁 文件` 区域，选择包含时序图像（如 `.png`, `.tif` 序列）的文件夹。
    - 点击 `🔄 加载帧`。
3.  **追踪操作**:
    - **选择神经元**: 在 `🧠 神经元选择` 区设定当前操作的 ID（如 N1, N2）。
    - **标记**: 在画布上 **左键点击** 神经元头部，或沿途添加“必经点”。
    - **计算**: 点击 `▶ 计算当前`，算法将自动连接各点并生成平滑路径。
    - **确认**: 确认无误后按 `Enter` 或点击 `✓ 确认` 保存。
4.  **结果导出**:
    - 在 `💾 导出` 区域选择导出视频、截图或 CSV 数据。

## 🧠 算法原理 (Algorithm Logic)

本工具的核心是基于图论的**最小代价路径搜索**。代价函数 (Cost Function) 定义如下：

$$ Cost = C_{distance} + \alpha \cdot C_{angle} + \beta \cdot C_{intensity} $$

- **$C_{distance}$**: 欧几里得距离，优先连接近邻点。
- **$C_{angle}$**: 角度惩罚项。如果路径方向与前一帧生长方向夹角过大（如 >60°），代价呈指数级增加。
- **$C_{intensity}$**: 像素强度项。优先选择图像中的高亮管状结构（轴突）。

通过调节 $\alpha$ 和 $\beta$ 参数（在界面“参数”区可调），可灵活适应不同信噪比的显微图像。
